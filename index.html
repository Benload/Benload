Predictor de Partidos de Tenis ATP

Sistema de machine learning para predicción de resultados de tenis profesional ATP, utilizando feature engineering temporal avanzado y algoritmos de clasificación basados en gradient boosting.

  • Feature Engineering Avanzado: Implementé rolling windows de rendimiento, métricas de momentum y sistema ELO multidimensional con 14 características especializadas.
  • Pipeline de Datos: Desarrollé procesamiento de 42,000+ partidos con prevención de data leakage mediante validación temporal.
  • Desafío Principal: Crear features temporales que capturen tendencias (velocity, acceleration) manteniendo integridad de datos históricos.
PythonXGBoostPandasNumPyscikit-learn

Juego Web Multijugador

Aplicación web full-stack de juego multijugador estilo tablero para 2-4 jugadores, con comunicación en tiempo real y mecánicas de juego sincronizadas.

  • Arquitectura Cliente-Servidor: Diseñé e implementé arquitectura completa con API RESTful en Koa.js y frontend React.
  • Tiempo Real: Desarrollé sistema de comunicación con WebSockets para sincronización de estado de juego, lobbies y turnos entre múltiples clientes.
  • Seguridad y Datos: Implementé autenticación JWT con bcrypt y modelado relacional con Sequelize ORM (PostgreSQL).
